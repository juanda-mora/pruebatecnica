Hola futuro Jefe, me llamo Juan y este es mi desarrollo de un CRUD funcional para un sistema de productos. El proyecto es un descargable .zip que puedes abrir desde tu ordenador, descomprimirlo y abrirlo en tu IDE favorito.
En este caso para el tema del desarrollo se usaron conceptos básicos pero funcionales de ArrayList, manejo de la Programación Orientada a Objetos, uso de constructores y métodos propios para su funcionamiento.
El proyecto cuenta con 3 clases principales y un archivo de DB, cada una separada de manera organizada para garantizar legibilidad en el proyecto.
