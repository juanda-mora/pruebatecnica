# Sistema CRUD de Productos

Aplicación desarrollada en Java para gestionar productos mediante operaciones CRUD.

## Tecnologías

- Java
- Maven
- JSON

## Estructura

```
src
 ├── entities
 ├── services
 ├── database
 └── Main.java
```

## Funcionalidades

- Crear productos
- Consultar productos
- Actualizar productos
- Eliminar productos
- Validación de datos
- Persistencia mediante archivo JSON de ejemplo
